# App de Movimentação

App de uso diário (celular) para centralizar a movimentação dos parques: roteiros de montagem e
desmontagem, pagamentos da movimentação e reembolsos de ajudante, com painel administrativo.

- Especificação completa: [ESPECIFICACAO.md](ESPECIFICACAO.md)
- Stack: Next.js (PWA) na Vercel + Supabase (banco, login e arquivos)
- Arquivos de apoio: [referencias/](referencias/)

Status: etapa (a), cadastros e login, em preparação.
